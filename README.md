# OverlayKiller

OverlayKiller は、Webページ上のオーバーレイや読書を妨げる固定広告・記事中広告を、**手動ワンプッシュで非表示にする** Chrome 拡張です。  
自動削除は行わず、ツールバークリックまたは右クリックメニューからのみ実行します。

## 主な機能
- オーバーレイ削除（close優先、失敗時は hide）
- 記事中広告のスコアリング削除
- 本文を覆う固定広告の削除
- 画面端の固定バナー削除
- Undo（直前の実行をまとめて復元）
- 設定UI（シグナルON/OFF、しきい値、最大削除数）
- 語彙ヒントの取り込み（`.txt` / `.json`）

## 使い方
1. Chrome で `chrome://extensions/` を開く
2. 「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
4. 任意ページで拡張アイコンをクリック、または右クリックメニューから実行

## 実行メニュー
- 広告/オーバーレイを削除（ワンプッシュ）
- Undo（直前の非表示を戻す）
- OverlayKiller 設定

## 注意
- 通信遮断（`webRequest` / `declarativeNetRequest`）は使いません
- 自動削除はしません
- 操作時のみ実行します
- Shadow DOM は open root の探索のみ対応します
